# Индивидуальный проект на семестр

**Тема:** Параметрически эффективная адаптация LLM к казахскому языку: влияние конфигурации LoRA на качество.

**Связь с диссертацией:** диссертация посвящена адаптации больших языковых моделей к казахскому языку методами PEFT (LoRA). Проект — первый эксперимент: какие настройки адаптера дают наибольший прирост при ограниченных ресурсах.

## Задача
Казахский — агглутинативный малоресурсный язык: одно слово несёт несколько суффиксов, данных мало, а многоязычные LLM отвечают на казахском заметно хуже, чем на английском (KazMMLU, ACL 2025). Полное дообучение дорого, поэтому используется LoRA. Вопрос проекта: **как ранг адаптера r и выбор слоёв (только attention или attention + MLP) влияют на качество модели на казахском** при одинаковом бюджете обучения.

## Данные
- **Обучение:** казахская Википедия (≈ 50–100 млн символов; сбор и очистка — из ПР 1), продолженное обучение языковой модели.
- **Оценка:** KazMMLU — казахская часть (вопросы с вариантами ответа); TUMLU-mini — казахская часть; отложенные 5 % казахских текстов для перплексии.

## Модель
Небольшая открытая многоязычная модель (Qwen2.5-1.5B или Llama-3.2-1B), библиотеки `transformers` + `peft`, одна GPU.

## Метрики
| Метрика | Что показывает |
|---|---|
| Accuracy на KazMMLU-kk и TUMLU-kk | знание языка и фактов (основная метрика) |
| Перплексия на отложенных казахских текстах | насколько модель «понимает» язык |
| Число обучаемых параметров и время обучения | цена адаптации |

## Baseline
1. **Базовая модель без адаптации** (zero-shot) — нижняя граница.
2. **Стандартная LoRA:** r = 8, адаптеры только на `q_proj`, `v_proj` — настройка «по умолчанию».

## Эксперименты
| # | Ранг r | Слои | Гипотеза |
|---|---|---|---|
| 1 | 8 | q, v | baseline LoRA |
| 2 | 32 | q, v | больший ранг помогает выучить новую морфологию |
| 3 | 8 | q, k, v, o + MLP | MLP-слои хранят «знания» о словах — важнее для нового языка |
| 4 | 32 | q, k, v, o + MLP | комбинированный вариант |

**Ожидаемый результат:** таблица «конфигурация → accuracy / перплексия / число параметров» и рекомендация, какую конфигурацию LoRA использовать для казахского при ограниченном бюджете.
